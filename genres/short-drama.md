# Genre: short drama, story, characters, dialogue

## Before any video
1. **Character Card** per character: age, face, hair, build, outfit, palette, signature prop, 1–2 small imperfections (scuffed shoes, a loose thread, tired eyes).
2. **Look Card**: era, location palette, lens, lighting, colour grade, texture.
3. Generate one reference image per character (and key locations) as images; get approval; reuse them as references in **every** shot.
4. Shot list: scene · characters · action · camera · emotion · dialogue line · duration.

## Shot rules
- 4–10 s per shot; one beat per shot; cut on action.
- Emotional beats in **React mode** (`craft/image-to-video.md`): ≥2 s per emotion change.
- Dialogue: one speaker per line, ≤2.5 words/second, head mostly still, framing locked. Exact lines on a specific face → render the shot, then a lip-sync capability.
- Max 2 interacting characters per shot; tag who is left/right and keep screen direction.
- Continuity ledger per shot: wardrobe, props (who holds what), light direction, last frame. For a continuation, use the previous clip's last frame as the next first frame.
- Re-use the same seed for near-identical retakes where the provider supports it.

## Structure (60–90 s vertical drama)
cold open conflict (0–5 s) → setup (5–20 s) → escalation (20–60 s) → twist or reveal (60–80 s) → hook for the next episode (last 5 s).

## Budget
Story work has the highest retake rate. Plan drafts for every shot, finalize only approved ones, and fix pacing in the edit.
